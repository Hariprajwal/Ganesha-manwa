🎨 Ganesha-Manhwa: The Future of Webtoon Automation
Ganesha-Manhwa is an experimental framework designed to automate the creation and narration of Manhwa-style content. By combining AI-driven storytelling with automated rendering pipelines, this project aims to reduce the manual labor in webtoon production.

🌟 Vision & Features
Automated Storyboarding: Utilizing LLMs to generate high-quality Manhwa scripts.

AI Voice Narration: Integrated support for models like Qwen3-TTS to create immersive "Narrator" experiences.

Anti-Gravity UI: A sleek, glassmorphic dashboard for managing assets.

Fast Rendering: Optimized processing via FFmpeg and GNU Parallel.

🛠 Tech Stack
Frontend: HTML5 / CSS3 (Semantic & SEO-optimized)

Logic: Python-based automation (Integrated with local LLMs)

Media: FFmpeg for video/audio stitching.
